# Hack The Box — Starting Point Writeups

Personal writeups for the **Hack The Box Starting Point** machines. Accessible to everyone.

## What is Hack The Box Starting Point?

[Hack The Box (HTB)](https://www.hackthebox.com/) is an online cybersecurity training platform. The **Starting Point** is a series of beginner-friendly machines designed to introduce core penetration testing concepts such as:

- Network enumeration with `nmap`
- Exploiting common services (FTP, SMB, HTTP, etc.)
- Privilege escalation techniques
- Using tools like `Metasploit`, `gobuster`, `john`, and more

## About This Repository

This repository contains step-by-step writeups for the HTB Starting Point machines. Each writeup documents the methodology, tools used, and commands run to pwn the machine — intended as a learning resource for anyone following along.

## Disclaimer

These writeups are shared for **educational purposes only**. They are published in accordance with Hack The Box's policy, which allows writeups for retired machines. Do not use the techniques described here against systems you do not have explicit permission to test.
